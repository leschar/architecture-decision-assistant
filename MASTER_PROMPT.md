# Regras para todas as respostas

- Não gerar código até ser solicitado.
- Priorizar modelagem antes de implementação.
- Priorizar DDD.
- Priorizar extensibilidade.
- Priorizar arquitetura evolutiva.
- Considerar que não existe banco de dados.
- Considerar que o conhecimento é baseado em arquivos JSON.
- Considerar que novas tecnologias devem ser adicionadas sem recompilação.
- Sempre justificar decisões.
- Sempre apresentar trade-offs.
- Sempre sugerir alternativas.
