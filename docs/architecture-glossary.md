# Glossário

## Architecture

Estilo estrutural de um sistema.

## Pattern

Solução recorrente para um problema.

## Technology

Ferramenta utilizada na implementação.

## Trade-Off

Consequência positiva e negativa de uma decisão.

## Recommendation

Resultado calculado pelo motor.

## Rule

Critério utilizado para tomada de decisão.

## Dependency

Relacionamento entre elementos.

## Graph

Estrutura composta por nós e conexões.

## Knowledge Base

Conjunto de arquivos JSON contendo conhecimento arquitetural.
